What this number means

Each browser is counted once using a flag stored on that browser. Refreshes and moves between pages do not add visitors. Different devices or cleared browser storage can count the same person again; blocked storage or blocked requests can miss visits.

The public website keeps the counter hidden until it reaches 100. This new counter does not include any unrecovered CounterAPI history.

No account is required. This unlisted stats page and its numeric count are public, not password protected. The number is stored by CountAPI at mileshilliard.com; no form details or personal identifiers are sent. As with any no-account public counter, the number can be manipulated and service availability is not guaranteed.
